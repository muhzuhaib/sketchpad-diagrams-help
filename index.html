Sketchpad user guide

Sketchpad adds editable diagrams to Confluence Cloud pages. All features are available on every licensed site. Sites with up to 10 users have a free starter price; larger sites are billed through Atlassian.

Add a diagram

  1. Open a saved Confluence page and enter page editing mode. If the page is new, publish it once before adding Sketchpad.
  2. Insert the Sketchpad Diagrams macro. Its fullscreen editor opens.
  3. Give the diagram a title. Draw shapes, connect arrows and add text, or choose Import file to open an editable .excalidraw drawing. Choose Import image to add a PNG, JPEG or WebP file, or paste an image from the clipboard.
  4. Choose Save diagram. This saves a new drawing revision and accepts the macro configuration.
  5. Publish or update the Confluence page to make that revision visible to readers.

Choose Cancel to leave the editor. If you changed the drawing, confirm whether to discard those changes. A failed save leaves your drawing in the editor so you can retry or download it.

Edit and read

Edit the page, select the macro and open its configuration to change the drawing. Each save creates a separate revision; earlier page versions keep their original references. Confluence handles competing page edits. To go back, choose an earlier save in Version history, then Save diagram: the earlier drawing becomes a new version and nothing is overwritten. Sketchpad does not offer simultaneous drawing collaboration.

Add images

Choose Import image or paste an image file into the editor. Sketchpad accepts PNG, JPEG and WebP images. It re-encodes the image in your browser to remove file metadata and scales it so neither side exceeds 2,048 pixels. Each processed image must fit within 1 MiB. A revision can contain up to 10 MiB of image data. Web image URLs, animated GIF files and embeds are not accepted.

Images remain editable canvas elements. They are included when you reopen the saved revision and when you download PNG or SVG output. Their bytes are stored separately from the scene in Atlassian-hosted Forge storage.

Reuse shapes with libraries

Choose Library to open three bundled starter items for flowcharts, architecture diagrams and planning. Choose an item to insert an editable copy into the current drawing.

To share your own reusable item, select one or more shapes and choose Add selection to library. The item becomes available from Library on every page in the same Confluence space. Anyone editing a page in the space can insert the shared items. To take an item out of the space library, choose the remove button beside it and confirm. Adding or removing an item requires page update permission and an active licence. A space library can hold up to 500 items or 1 MiB of validated shape data. Images, external links and custom element data cannot be added to a library.

Import Mermaid

Choose Import Mermaid, paste a Mermaid flowchart or sequence diagram, then choose Preview diagram. The editable shapes appear on the canvas while the dialog remains open. Choose Insert diagram to keep them, or Cancel to return to the unchanged drawing. Invalid text shows an error without removing existing work. Mermaid text is limited to 20 KiB and is converted locally in the browser.

Readers see the diagram title and an interactive canvas. Zoom or pan to inspect the diagram. Page read access is required. Page update access and an active Sketchpad licence are required to save. Anonymous users are not supported. When a licence expires, existing diagrams remain viewable and downloadable.

Download or move a diagram

Select Editable file, PNG image or SVG image, then choose Download. Editable files can be imported into Sketchpad or another compatible Excalidraw editor. PNG exports fit within 4,096 pixels on their longest side. SVG keeps vector shapes and embedded local font data. Downloads go to your device.

To copy a drawing to another page, download its editable file and import it into a new macro on the destination page. A copied page cannot read the source page's Sketchpad revision. Local exports are the portable backup format.

Drawing limits

Shapes, text, arrows, freehand strokes, frames and local images are supported. Web embeds, external element links and custom element metadata are not supported. Import uses the Import file or Import image button; file drops are disabled. A drawing can have up to 1,000 elements and its scene JSON must fit within 180 KiB. Each image can use up to 1 MiB after processing, with 10 MiB of images per saved revision. Editable drawing imports may be up to 1 MiB. Very large drawings should be split into smaller diagrams.

Use the toolbar and canvas menu for drawing controls and Download for exports. The native right-click menu, link shortcut and command palette are disabled.

Use the canvas menu to change its background, switch light/dark canvas mode or reset the canvas. Undo and redo work in the editor. Changes must be saved before leaving. No Jira integrations are included.

Troubleshooting

If a drawing will not open, check that you can read the saved page and that the macro was not copied from another page. If saving is disabled, check page update permission and the app licence with your site administrator. If a save fails, keep the editor open and retry; download an editable file before closing it. An unavailable saved revision cannot be reconstructed from the page title.

For a new installation, your site administrator installs Sketchpad from Atlassian Marketplace. No external account or service is required. Uninstalling the app removes access to stored diagrams; export drawings you want to retain first. Reinstalling does not automatically restore old storage.

Sketchpad privacy policy

Effective 10 October 2026. Provided by zuhaib.

Sketchpad processes diagram titles, drawing elements and canvas background colours. It stores these as immutable revisions in Atlassian-hosted Forge Key-Value Store, isolated by installation and Confluence page. Page identifiers and randomly generated revision identifiers form storage keys. Each revision also records the time it was saved and the identifier of the revision it was edited from, so the editor can list earlier versions. Sketchpad does not store account profiles, email addresses or account IDs with drawings.

PNG, JPEG and WebP images that an editor imports or pastes are decoded and re-encoded in the browser to remove file metadata. Each processed image is at most 2,048 pixels on either side and 1 MiB. Sketchpad stores image bytes in separate Forge records scoped to the same page as the drawing. A stored image cannot be changed after upload, and the saved revisions of that page that use it share one copy. Image data remains in Atlassian-hosted Forge storage and is loaded only through a revision that references it.

When an editor adds selected shapes to the shared library, Sketchpad stores the shape data and its label in Forge storage under the current Confluence space. Anyone who can read a page in that space can load those library items. Adding or removing an item requires page update permission and an active licence. A removed item is deleted from the space library. The library does not store the account ID of the person who added an item.

Atlassian supplies the current user's account identity and app licence during requests. Sketchpad uses them to check Confluence page permissions and licence status. The app requests storage access and page permission checks. It does not request page content, user profile, email, or external network permissions.

The app has no external backend, telemetry, analytics, advertising, crash-report service or collaborative drawing service. Fonts and editor assets are bundled. It does not transmit diagrams to Excalidraw's hosted service. Local imports are read in the browser; Mermaid text is converted by bundled code in the browser; local exports are downloaded to the user's device. Mermaid text is not stored separately. Its converted shapes become part of a revision only after saving. Support correspondence is handled separately and should not include sensitive drawings or account credentials.

Saved revisions remain while the installation retains its storage. Removing a macro or page does not automatically erase saved revisions because earlier page versions can still refer to them. Export drawings before uninstalling. Atlassian manages storage retention and disposal after uninstallation. A reinstall is a new installation; storage recovery is subject to Atlassian's recovery process and retention policy, rather than an automatic restore by Sketchpad.

Forge-hosted storage follows the host application's data residency location. Atlassian's platform safeguards and customer administration apply. This policy does not claim a separate certification for Sketchpad.

For privacy, export or deletion enquiries, contact support.zuhaib@gmail.com. Site administrators can remove the installation. The Forge data lifecycle and recovery rules are documented at https://developer.atlassian.com/platform/forge/storage-reference/hosted-storage-data-lifecycle/.

Sketchpad support

Contact support.zuhaib@gmail.com for installation, drawing or export problems. Include the app version, browser name, the action that failed and the exact error message. A description of the problem is usually sufficient. Do not send passwords, API tokens or sensitive diagrams.

Sketchpad supports Confluence Cloud in current desktop Chrome, Edge, Firefox and Safari. The automated browser suite runs on Chromium, Firefox and WebKit. Drawing on a larger screen gives more room for the canvas. Internet access to Atlassian is required to load the app and save revisions.

Atlassian handles billing, subscription changes and refunds through the Marketplace purchase. Your Confluence administrator manages page permissions and app installation. Sketchpad support does not change your page permissions.

No response-time SLA is promised. Sketchpad does not include Jira integration, web embeds or real-time collaboration.

Sketchpad security policy

Report a suspected vulnerability to support.zuhaib@gmail.com. Include the app version, affected action and a minimal reproduction. Do not send credentials, private customer diagrams or exploit another customer's installation.

Sketchpad runs on Atlassian Forge. It has no external backend or telemetry. Every drawing request checks the current user's page permissions. Saving also requires an active app licence. Data is isolated by installation and page. The trusted resolver supplies identity and licence; browser values do not override them. Fonts and drawing assets are bundled locally.

The release pipeline checks dependencies with npm audit, rejects broader manifest permissions and private artifacts, and verifies authorization and malformed-input behavior. Updates follow the same review and verification process. No separate certification, bug bounty or penetration-test claim is made.

The provider follows Atlassian's Marketplace security bug fix policy. Cloud remediation deadlines are 10 days for critical, 4 weeks for high, 12 weeks for medium and 25 weeks for low severity, measured under Atlassian's reporting and triage rules. Security incidents are reported to Atlassian and affected customers without undue delay. This is not a customer support response-time SLA.

Platform policy: https://developer.atlassian.com/platform/marketplace/security-bugfix-policy/. For data handling and retention, see the privacy policy and provider terms.
